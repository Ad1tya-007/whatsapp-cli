# wacli 1.0.3

Release notes for new commands and documentation split.

## Summary

1.0.3 adds practical CLI commands (contacts, check, me, media send, configurable chat list) and splits docs into a simple user README and a developer guide.

## New commands

- `contacts` — list saved contacts (name + number)
- `check -n <number>` — check if a number is registered on WhatsApp (no message sent)
- `me` — show the logged-in WhatsApp account (name / number)

## Enhancements

### Send
- `-f, --file <path>` — send an image, document, or other file
- `-m, --message` is optional when sending a file (used as caption)

### List
- `-l, --limit <n>` — how many recent chats to show (default: 5)

## Documentation

- `README.md` — end-user guide (`wacli` install and usage only)
- `DEVELOPER_README.md` — build, architecture, session path, and contributor notes
- `QUICK_START.md` updated for the new commands and dual READMEs

## Version

- Package and CLI `--version` bumped to `1.0.3`

## How to verify

```bash
npm install
npm run build
npm link   # if using the global wacli binary

wacli me
wacli contacts
wacli check -n <countrycode><number>
wacli list -l 10
wacli send -n <countrycode><number> -m "Hello from CLI"
wacli send -c "Contact" -f ./photo.jpg -m "Caption"
```
