# wacli 1.0.4

Release notes for contact resolution, media validation, and source layout.

## Summary

1.0.4 improves `-c` contact matching (saved contacts first, interactive picker fallback), adds stricter media validation, and restructures `src/` for clearer boundaries.

## Contact resolution (`-c`)

- Prefer **saved contacts** (`isMyContact` + saved name match)
- If none match, show up to **5** name/pushname candidates in an interactive up/down picker (name + number)
- Exact saved-name match is preferred when multiple saved contacts match

## Video files are not supported

**Video sending is not allowed in 1.0.4.** `wacli` rejects video files passed to `-f`.

- Videos cannot be sent as playable media
- Videos cannot be sent as documents
- Common video extensions and `video/*` MIME types are rejected
- Validation happens before the WhatsApp client starts
- Will be added in the future.

## Browser and session handling

- All commands use the same browser (system Chrome when installed), so the shared session profile stays compatible
- Fails fast with an actionable message when the saved session was written by a newer Chrome, instead of hanging for 30 seconds
- Teardown waits for the browser process to exit cleanly
- A `LOGOUT` disconnect now reports that the device was signed out instead of crashing with a stack trace

## Source restructure

```
src/
  index.ts
  cli/           # Commander commands + withClient lifecycle
  client/        # WhatsApp client, session, Chrome path
  services/      # messaging, contacts, media, chats, account
  utils/         # phone + ID helpers
```

## Version

- Package and CLI `--version` bumped to `1.0.4`

## How to verify

```bash
npm install
npm run build
npm link   # if using the global wacli binary

wacli --version
wacli send -c "PartialName" -m "Hello"   # picker if not in saved contacts
wacli send -n <countrycode><number> -f ./document.pdf -m "Caption"

# Expected to fail before connecting:
wacli send -n <countrycode><number> -f ./video.mp4
```
