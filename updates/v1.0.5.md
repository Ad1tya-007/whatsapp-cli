# wacli 1.0.5

Release notes for the command registry layer.

## Summary

1.0.5 introduces a **command layer**: each CLI command is a self-contained module loaded into a registry Map. Commander remains the argument parser. WhatsApp logic stays in `src/services/`. Public commands and flags are unchanged.

## Command registry

Commands live in `src/cli/commands/` and default-export a definition (`name`, `description`, options, optional `validate`, `run`).

The registry loads every command file into a `Map` (`send` → SendCommand, …). `program.ts` binds those definitions to Commander and runs:

1. `validate` (before connecting — e.g. send media / `-n` vs `-c`)
2. `withClient` → `run(client, options)`, unless `needsClient: false` (`logout`)

Adding a command is: drop a file in `src/cli/commands/`. No edits to `program.ts`.

```
CLI (Commander) → Command Registry (Map) → command.run(...) → services
```

## Version

- Package version bumped to `1.0.5`
- CLI `--version` reads `package.json` (single source of truth)

## How to verify

```bash
npm install
npm run build
npm link   # if using the global wacli binary

wacli --version          # 1.0.5
wacli --help             # same commands as 1.0.4
wacli send --help
wacli logout             # still works without starting Chrome
```
